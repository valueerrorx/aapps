# aapps

Kleine Android-Werkzeuge, jedes mit genau einer Aufgabe: schön, schnell, offline. Geschwister von [sleepr](https://github.com/valueerrorx/sleepr).

## Apps
- **levlr** – Wasserwaage und Neigungsmesser
- **nordr** – Kompass
- **spinr** – Glücksrad
- **scorr** – Punktezähler
- **focusr** – visueller Fokus-Timer
- **roundr** – Intervall-Timer
- **pulsr** – Metronom
- **loudr** – Schallpegelmesser
- **tunr** – Instrumenten-Stimmer

Stand und Reihenfolge: [docs/PLAN.md](docs/PLAN.md).

## Prinzipien
- Keine Werbung, kein Tracking, kein Account.
- Keine Internet-Berechtigung: was die Apps messen, bleibt am Gerät.
- Open Source unter GPLv3.
